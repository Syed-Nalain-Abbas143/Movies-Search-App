# 🎬 Movie Search App
 
A modern, responsive React + Vite application that lets you search and discover movies using the OMDB API.
 
---
 
## ✨ Features
 
- 🔍 **Real-time Movie Search** - Search for any movie and get instant results
- 🎨 **Beautiful UI** - Modern design with gradient background and glassmorphism effects
- ⚡ **Fast & Smooth** - Built with Vite for lightning-fast performance
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- 🔒 **Secure** - API key stored safely in environment variables
- ⏳ **Loading States** - Visual feedback with spinner while fetching data
- ❌ **Error Handling** - Helpful error messages for failed searches
- 🎯 **Default Movies** - Shows popular movies on page load
- ⌨️ **Keyboard Support** - Press Enter to search
- 🖼️ **Image Fallbacks** - Gracefully handles missing movie posters
---
 
## 🛠️ Tech Stack
 
- **React 18** - UI library
- **Vite** - Build tool & dev server
- **Axios** - HTTP client for API requests
- **Tailwind CSS** - Styling
- **OMDB API** - Movie database
---

# 📖 Usage
 
### Search for Movies
 
1. Enter a movie title in the search box
2. Click **"Search"** button or press **Enter**
3. Results will appear below
### Features in Action
 
- **Default Movies** - Page loads with "Hulk" movies
- **Loading Spinner** - Shows while fetching data
- **Error Messages** - Displays if search fails or no results found
- **Movie Cards** - Shows poster, title, year, and type
- **Hover Effect** - Cards scale up on hover
